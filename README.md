# Cérebro - Sistema Desktop com Resposta por Voz

Cérebro é um inovador sistema desktop que combina as funcionalidades de um dicionário e uma calculadora. Ele permite que o usuário insira cálculos ou pesquisas por meio de texto ou comando de voz, fornecendo respostas audíveis diretamente do sistema. Esse projeto foi desenvolvido com **JavaFX** e funciona no **Windows 7**. **Cérebro** conquistou o **terceiro lugar** em uma feira de tecnologia, destacando-se pela interatividade e acessibilidade.

## Funcionalidades Principais

- **Dicionário Interativo**: Permite que o usuário pesquise palavras ou expressões, obtendo as definições por meio de áudio.
- **Calculadora Inteligente**: Suporta cálculos complexos e fornece os resultados em forma de voz.
- **Comandos de Voz**: O sistema reconhece comandos de voz, permitindo que o usuário fale suas consultas ou cálculos.
- **Interface Amigável**: Desenvolvido com JavaFX, o sistema oferece uma interface simples e intuitiva.

## Tecnologias Utilizadas

- **JavaFX**: Para o desenvolvimento da interface gráfica.
- **API de Reconhecimento de Voz**: Para os comandos e respostas em áudio.
- **Java**: Linguagem principal para lógica de programação.

## Como Funciona

1. **Entrada por Texto**: O usuário pode digitar cálculos ou consultas no dicionário.
2. **Entrada por Voz**: O sistema reconhece os comandos de voz e processa as consultas.
3. **Saída por Áudio**: As respostas (sejam resultados de cálculos ou definições de palavras) são fornecidas audivelmente pelo sistema.

## Requisitos do Sistema

- **Sistema Operacional**: Windows 7 ou superior
- **Java JDK**: Versão 8 ou superior
- **Bibliotecas de Voz**: Necessárias para o funcionamento dos comandos e respostas de voz.
